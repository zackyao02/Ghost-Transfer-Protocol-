# 游戏设计与关卡（GDD）

## 1. 核心循环

```text
校准身体 → 施法战斗 → 读取记忆 → Ghost 决策
→ Boss 变化 → 神降收容 → 玩家选择 → 世界留下变化
```

## 2. 操作设计

### 玩家可见操作

| 动作 | 用途 | 判定目标 |
|---|---|---|
| 食指指向并停留 | 选择目标或结局 | 稳定、容错大 |
| 拇指与食指捏合 | 确认 | 单次触发 |
| 食指横划 | 剑诀协议 | 快速、明确 |
| 食指宽松画圈 | 净化符文 | 约 270° 自动补全 |
| 张掌保持 0.6～0.8 秒 | 校准、神降协议 | 进度环反馈 |

### 隐藏导演操作

- `1`：剑诀。
- `2`：净化符。
- `Q`：神降。
- `R`：重置当前流程。
- `F1`：显示调试面板。
- `F2`：载入“善意 Ghost”存档。
- `F3`：载入“敌意 Ghost”存档。

键盘、鼠标和手势必须调用同一套语义事件，不允许分别实现技能逻辑。

## 3. 关卡时间线

### 第一幕：神龛校准（0～15 秒）

- 黑暗场景中只突出机械神龛与手掌轮廓。
- 张掌时神龛逐层点亮，进度环同步增长。
- 完成后 Ghost 核心苏醒：“身份残片 07，等待新壳。”

### 第二幕：污染庭院（15～40 秒）

- 镜头自动移动到庭院节点，无自由移动。
- 两只石精从朱红数据裂缝中出现。
- 玩家通过横划释放剑诀；成功动作保留明显残影和命中停顿。

### 第三幕：记忆祭坛（40～65 秒）

- 玩家画圈形成净化符，开启祭坛。
- 展示上一位玩家留下的一条记忆。
- Agent 根据记忆、世界污染和本局表现选择“护主、旁观、伪装”。

### 第四幕：山魈 Boss（65～105 秒）

- 山魈从神龛后方进入，占屏幕高度约 35%。
- Boss 攻击前出现朱红地面预警。
- Ghost 根据 Agent 决策挡伤、拒绝协助或夺取山魈义体。
- 玩家使用剑诀破甲、净化符造成范围伤害。

### 第五幕：神降与抉择（105～140 秒）

- 张掌保持触发法阵、法相和收容扫描。
- Boss 被收容后出现三个大型符印：封存、共生、换壳。
- 玩家指向并捏合确认。
- 场景立即发生可见变化并写入存档。

## 4. 三种结局

| 选择 | 本局表现 | 下一局变化 |
|---|---|---|
| 封存 | Ghost 被压入神龛，增加红色封条 | 信任下降，Boss 更具攻击性 |
| 共生 | Ghost 进入青金守护状态 | 下局主动替玩家挡一次攻击 |
| 换壳 | Ghost 转移到 Tripo 义体 | 技能、属性和外观发生变化 |

## 5. 可复现的涌现

### 存档 A：被善待的 Ghost

- 历史为连续共生。
- Boss 战中 Ghost 自动挡下一次致命攻击。
- 结局界面主动推荐共生，但玩家仍可拒绝。

### 存档 B：被反复封存的 Ghost

- 历史为多次删除和封存。
- Ghost 先伪装协助，在神降前夺取山魈义体。
- 玩家必须完成第二次短暂收容。

## 6. 战斗数值基线

- 石精：2 只，每只 2 次剑诀或 1 次净化符击败。
- 山魈：三段血量，仅表现为破甲、暴露核心、可收容，不做复杂多阶段 AI。
- 剑诀冷却：约 0.8 秒。
- 净化符冷却：约 2 秒。
- 神降：剧情充能，Boss 核心暴露后可用。
- 玩家失败：不进入长 Game Over，Ghost 将玩家拉回祭坛并降低难度。
