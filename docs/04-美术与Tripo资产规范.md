# 美术与 Tripo 资产规范

## 1. 视觉主题

原创“东方赛博神社”，借用灵魂、身体、记忆与身份连续性的母题，不使用现有影视 IP 的角色、Logo、台词或原画。

### 固定色板

- 炭黑 `#090A0F`：建筑、废墟和背景。
- 青绿 `#39E6D0`：Ghost、记忆和正常数据。
- 朱红 `#E44732`：污染、敌人与危险预警。
- 符金 `#E7C45A`：守护、法阵和神降。

## 2. 场景构图

- 前景：手势轨迹、符纸、火星、低矮残骸。
- 中景：机械神龛、祭坛、敌人和 Ghost 核心。
- 后景：破庙轮廓、城市霓虹、数据雨和雾。
- Boss 首次出现时占屏幕高度约 35%，普通敌人必须远看可辨。
- 黑暗区域保留冷蓝灰补光，不允许大面积纯黑失去结构。

## 3. Tripo 生成清单

### P0 资产

| 资产 | 用途 | 预算 |
|---|---|---:|
| 山魈异常 AI | Boss、换壳核心 | 15k～30k 三角面 |
| 守护 AI 法相 | 神降演出 | 8k～20k 三角面 |
| 石精数据体 | 普通敌人 | 3k～8k 三角面 |
| 机械神龛/祭坛 | 场景视觉中心 | 8k～20k 三角面 |

### P1 资产

- 镇煞型 Ghost 义体：符甲、厚重、防御。
- 逃逸型 Ghost 义体：青色、轻型、速度。
- 污染型 Ghost 义体：朱红裂纹、兽形、攻击。

## 4. 生成要求

- 单体、全身、纯色背景、无地面和无环境特效。
- 角色使用 A-Pose 或 T-Pose，四肢与身体分离清楚。
- 正面与侧面结构明确，避免复杂透明薄片和大量悬空零件。
- 不在参考图中加入雾、火焰、拖尾或强烈景深。
- Hero 资产使用“最高质量＋干净拓扑”。
- 角色优先导出 `FBX + PNG`，静态物件可使用 FBX 或 GLB。
- 纹理使用 1K 或 2K，避免比赛现场加载过大。

## 5. Unity 导入标准

- 1 Unity 单位 = 1 米。
- Y 轴向上，原点位于脚底或物体底部中心。
- 角色正面统一为项目约定方向。
- 材质统一转为当前渲染管线支持的 Shader。
- 每个资产制作 Prefab，并设置碰撞体、LOD 与挂点。

角色挂点：

```text
Head
Chest
Hand_L
Hand_R
Foot_L
Foot_R
VFX_Hit
VFX_Spawn
VFX_Death
```

## 6. VFX 与音效

- 剑诀：青白横向残影，命中白闪与短暂停顿。
- 净化符：金红轨迹闭合，落地形成短暂净化区域。
- 神降：金白法阵、法相剪影、收容扫描和 2～3 秒高潮。
- 敌人死亡：朱红数据裂解，不使用普通爆炸。
- 每个识别阶段都有不同提示音：找到手、候选动作、确认释放、失败复位。

## 7. 资产验收

- 不看文字也能区分石精、山魈和法相。
- 三种技能的轮廓、时间和声音均有差异。
- 山魈轮廓必须体现驼背、长臂、红眼和义体噪声。
- 神降必须是全局最强视觉瞬间。
- Tripo 原始文件、导出文件和 Unity Prefab 分目录保存。
