# 产品需求文档（PRD）

## 1. 产品定义

**项目名：**《请神协议：新港市镇煞》  
**英文副标题：**Ghost Transfer Protocol  
**类型：**AI 驱动的体感仪式战斗与持续世界 Demo  
**平台：**Windows Unity 可执行版优先  
**单局时长：**120～150 秒

### 一句话介绍

玩家通过手势在赛博神社中镇压异常 AI，却发现山魈体内的 Ghost 会记住历代玩家的选择、转移义体，并改变下一位玩家进入的世界。

### 核心价值

- 身体交互：玩家不依赖传统键鼠即可完成一场仪式。
- 数字生命：Ghost 具有连续记忆，而不是一次性生成角色。
- 持续世界：本局选择会改变下一局可见的场景、阵营和行为。
- AI 3D：Tripo 生成的义体不仅改变外观，也映射到能力和行为。

## 2. 目标用户与使用场景

- 黑客松评委：3 分钟内理解创新点并完成一次关键互动。
- 展会观众：无需学习复杂按键，站到摄像头前即可体验。
- 直播观众：能够从画面直接理解手势、技能和 Ghost 选择。

## 3. 核心体验指标

- 新玩家 10 秒内明白第一个动作。
- 不使用键盘和鼠标可完成主流程。
- 手势动作后 80 ms 内出现预反馈，180 ms 内确认技能。
- 一局不超过 150 秒。
- 刷新或重启后至少三项世界状态保留。
- 摄像头、网络或 Agent 任一失败时仍能完成演示。

## 4. 用户流程

1. 玩家进入废弃神社网络节点。
2. 张掌保持，完成手部校准并唤醒 Ghost。
3. 横划施放剑诀，击败石精。
4. 画圈完成净化符，解锁记忆祭坛。
5. Agent 读取 Ghost 历史并决定本局意图。
6. 山魈 Boss 出场，Ghost 根据记忆协助、旁观或背叛。
7. 玩家张掌触发神降协议，完成收容。
8. 玩家指向并确认“封存、共生、换壳”之一。
9. 选择写入世界状态，影响下一位玩家。

## 5. 功能范围

### P0：必须完成

- 一个赛博神社场景与固定镜头流程。
- 石精、山魈、守护法相三类角色表现。
- 剑诀、净化符、神降三种技能。
- Python MediaPipe 手势输入与 Unity 统一输入路由。
- 键盘、鼠标导演兜底。
- 一个 World Director Agent 的真实结构化决策。
- 封存、共生、换壳三个结局。
- 本地世界状态持久化。
- 两个可复现的评审存档。
- Windows 可执行版与备用录屏。

### P1：有余力再做

- Tripo 现场生成一个义体并异步替换展示位。
- Ghost 记忆谱系可视化。
- WebGL 版本。
- 观众扫码领取 Ghost 卡片。

### 明确不做

- WASD 自由探索。
- 开放世界、多地图、多 Boss。
- 多 Agent 社会模拟。
- 大型技能树、装备与养成系统。
- 双手复杂连续动作作为通关必需条件。
- 实时生成完整关卡或必须等待的在线流程。

## 6. 成功标准

- 20 次连续完整演示无流程卡死。
- 评委能准确复述“Ghost 会记住并改变下一局”。
- Agent 决策至少真实改变一次 Boss 行为或阵营。
- Tripo 资产至少有一种属性映射到玩法。
- 主流程在断网状态下仍可完成。
