# 里程碑与验收标准

## Gate 0：Unity 基线验证（0～2 小时）

- 三人拉取 GitHub 主仓库 `master`。
- Unity 源码统一放入 `unity/ai-project/YaowuDemo`。
- Unity 正常打开 `ai-project/YaowuDemo`。
- 清除阻塞编译错误。
- 找到主场景并运行。
- 完成一次 Windows x64 空构建。
- 创建三个功能分支和 `integration/demo`。

**出口：**所有人基于同一 Unity 版本看到同一个可运行场景。

## Gate 1：灰盒闭环（2～10 小时）

- A：场景灰盒、镜头节点、刷怪点与 Boss 点位。
- B：角色占位 Prefab 与三技能占位 VFX。
- C：键盘技能、敌人受伤、Boss、神降与结局选择。

**出口：**不依赖手势和网络，可以从开场打到结局。

## Gate 2：输入与第一次美术集成（10～22 小时）

- Python 仅发送 JSON。
- Unity 收到横划、画圈和张掌事件。
- 动作状态机、复位和去重生效。
- 山魈、法相和场景第一版进入 `integration/demo`。
- 完成第一次三人共同试玩。

**出口：**手势可完成主要战斗，断线不影响键盘通关。

## Gate 3：Agent 与持续世界（22～32 小时）

- Ghost 记忆保存和读取。
- Agent 输出护主、旁观或伪装之一。
- 决策真实改变 Boss 战。
- 三个结局改变下一局状态。
- 两个评审存档可一键载入。

**出口：**刷新或重启后可见世界变化。

## Gate 4：表现与体验打磨（32～42 小时）

- Boss 出场、受击、破甲与死亡反馈完整。
- 神降演出达到 2～3 秒并成为视觉高潮。
- UI 隐藏开发感，动作提示与世界观统一。
- 完成音效、灯光和性能降级。

**出口：**新玩家 10 秒理解操作，150 秒内完成一局。

## Gate 5：封版与提交（42～48 小时）

- 禁止新增系统。
- 连续完整演示 20 次。
- 测试断网、无摄像头、服务崩溃和 Agent 超时。
- 生成 Windows 构建、README、备用视频和截图。
- 完成 4 分钟路演与 3 分钟问答排练。

## 最终验收清单

### 构建

- [ ] 新电脑按说明可以启动游戏。
- [ ] Python 服务未启动时 Unity 不崩溃。
- [ ] 所有正式素材本地可用。

### 手势

- [ ] 横划 10 次至少成功 9 次。
- [ ] 张掌 10 次至少成功 9 次。
- [ ] 指向与捏合 10 次至少成功 9 次。
- [ ] 画圈 10 次至少成功 7～8 次。
- [ ] 静止 30 秒误触发为 0。
- [ ] 一个动作只触发一次。

### 玩法

- [ ] 键盘、鼠标、手势调用相同技能接口。
- [ ] 无自由移动也能完成完整关卡。
- [ ] Boss 行为至少受一次 Agent 决策影响。
- [ ] 三个结局都能进入下一局。

### 表现

- [ ] 场景一眼可识别为东方赛博神社。
- [ ] 石精、山魈和法相轮廓明确。
- [ ] 剑诀、净化符和神降反馈不同。
- [ ] 低亮度下仍能看清场景结构和敌人。

### 赛道证明

- [ ] Agent 的输入、意图、工具和结果可观察。
- [ ] Tripo 义体映射到属性或行为，不只是换皮。
- [ ] 下一局可见上一位玩家留下的变化。
- [ ] 两个评审存档产生明显不同结果。
