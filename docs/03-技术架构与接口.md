# 技术架构与接口

## 1. 总体架构

```text
摄像头
  ↓
Python / OpenCV / MediaPipe
  ↓ localhost:8765，长度头 + UTF-8 JSON
Unity GestureInputRouter
  ↓
GameFlowController → SkillCaster → Combat/VFX/UI
  ↓
WorldDirectorAgent → 白名单工具 → WorldStateStore
```

## 2. Python 手势服务

现有 `hand_tracking_server.py` 使用 TCP 端口 `8765`，方向正确，但正式版应调整为：

- 删除逐帧 JPEG 发送。
- 仅发送 JSON 状态和动作事件。
- 推理频率固定为 15～30 FPS，不无限堆积帧。
- 摄像头只由 Python 占用。
- 使用本地 `hand_landmarker.task`，不依赖外网。
- 服务断开不阻塞 Unity 主线程。

### 消息示例

```json
{
  "type": "gesture_recognized",
  "gesture": "SwordQi",
  "confidence": 0.91,
  "trace_id": "gesture-001",
  "timestamp": 1720000000.32
}
```

允许事件：

```text
hand_state
gesture_candidate
gesture_recognized
camera_status
performance
error
```

## 3. Unity 核心模块

### GestureInputRouter

统一接收：

```csharp
SelectTarget(targetId)
ConfirmTarget(targetId)
CastSkill(SkillType.SwordQi)
CastSkill(SkillType.FireTalisman)
CastSkill(SkillType.DeitySummon)
ResetFlow()
```

职责：

- 手势、鼠标、键盘映射为同一语义事件。
- 按 `trace_id` 去重。
- 维护输入上下文：校准、战斗、选择、过场。
- 服务断开后切换导演模式。

### GameFlowController

流程状态：

```text
Boot → Calibration → TutorialCombat → MemoryAltar
→ BossIntro → BossCombat → DeitySummon → FinalChoice → Result
```

所有状态必须可重置、可跳转、可由导演模式载入。

### SkillCaster

- 只接受统一输入事件。
- 管理冷却、命中、伤害和技能事件。
- 通过事件通知 VFX、音效和 UI，不直接持有美术对象。

### WorldStateStore

本地 JSON 即可，建议字段：

```json
{
  "cycle": 7,
  "corruption": 42,
  "ghost": {
    "trust": -20,
    "shell": "shanxiao_shell",
    "memories": []
  },
  "scars": [],
  "last_choice": "seal"
}
```

### WorldDirectorAgent

- 只在记忆祭坛或 Boss 登场前调用一次。
- 输入为结构化世界状态，不传递无限历史。
- 输出严格 JSON；解析失败立即使用规则化回退。
- 只允许调用以下工具：

```text
set_ghost_attitude
select_shell
modify_boss_behavior
add_world_scar
write_memory
select_next_event
```

Agent 超时、断网或返回非法结果时，使用当前存档中的预设意图继续游戏。

## 4. 手势状态机

```text
NO_HAND → ACQUIRING → READY → RECORDING
→ CANDIDATE → CONFIRMED → COOLDOWN
→ NEUTRAL_RESET → READY
```

强制规则：

- 所有距离和速度按掌宽归一化。
- 使用 EMA 或 One Euro Filter 平滑关键点。
- 确认阈值与取消阈值分离，避免边界抖动。
- 未通过中立复位不得重复触发。
- 每个游戏上下文只开放当前需要的动作。
- 低置信度只显示提示，不猜测释放。

## 5. 性能预算

| 模块 | 目标 |
|---|---:|
| Unity 渲染 | 稳定 60 FPS，最低不低于 30 FPS |
| MediaPipe 推理 | 15～30 FPS |
| 手势预反馈 | 小于 80 ms |
| 技能确认 | 小于 180 ms |
| Agent 请求 | 目标 3 秒内，5 秒超时回退 |
| 输入断线降级 | 1 秒内完成 |

## 6. 构建策略

- 第一目标：Windows x64。
- 所有模型、MediaPipe 文件、音效和评审存档本地化。
- 生成版本必须包含一键启动说明。
- WebGL 只有在 Windows 版本稳定后再尝试。
